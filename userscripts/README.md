# Instagram 浏览同步（油猴脚本）

正常刷 Instagram 时，自动把看过的图片/视频同步到本地画廊。**只收集页面上已经加载过的媒体地址**，不产生任何额外的 IG 请求——浏览节奏就是唯一的请求节奏，这是对账号最安全的采集方式。

## 工作原理

```
浏览器（instagram.com）                本机（blissful-faraday）
┌──────────────────────┐   POST       ┌────────────────────────────┐
│ 油猴脚本收集当前页面   │ ──────────→ │ /api/instagram/harvest     │
│ 已加载的媒体 CDN 地址  │  新媒体地址   │ 下载到 ~/Pictures/         │
│ （MutationObserver）  │ ←────────── │ instagram-scraped/{用户名}/ │
└──────────────────────┘  下载结果摘要  └────────────────────────────┘
```

- 采集范围：个人主页（含点开帖子后的浮层）+ **首页时间线**（按帖子卡片的作者链接归属）+
  从时间线点开的帖子浮层；轮播帖只存你实际翻到的帧，Stories 不采集，广告帖可能一并入库
- 自动尝试把网格缩略图 URL 还原为全尺寸（去掉 IG 的尺寸段），失败则存缩略版
- 以 CDN 路径中的媒体 ID 去重：同一张图换签名、换尺寸都只存一次
- 视频策略：优先从 React Fiber/内部状态解析官方下发的原生高清 MP4 直链（只要滑到立刻后台秒存全长完整原档，无需看完）→ 整段 Blob 直读 → 分片拼装/实际链接下载 → 实时录制兜底
- 彻底屏蔽视频预览图：扫描时智能识别视频卡片与播放标识，视频封面/占位图在源头直接拦截，不作为图片下载，确保相框图集纯粹无冗余
- 新图集落地后，画廊靠目录 mtime 变化自动重建缓存，无需手动重扫

## 安装与自动更新

### 方式 1：通过画廊直链一键安装 / 自动更新（推荐）
1. 浏览器安装 [ScriptCat（脚本猫）](https://scriptcat.org/) 或 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 在浏览器中直接打开画廊脚本直链：
   `https://gallery.example.com:8443/userscripts/blissful-harvest.user.js`
   （扩展会自动弹出安装界面，点击「安装」即可）
3. 脚本内置 `@updateURL` 与 `@downloadURL`，未来画廊升级时，ScriptCat / Tampermonkey 会**自动静默检查并完成更新**！
4. 浏览器打开画廊（`https://gallery.example.com:8443` 或 `http://localhost:3000`）**登录一次**——脚本回传需要画廊的会话 cookie
5. 打开任意 Instagram 个人主页或时间线，左下角出现 `📥` 徽章即在工作

### 方式 2：手动复制粘贴安装
1. ScriptCat / Tampermonkey 面板 → 添加新脚本 → 粘贴 `blissful-harvest.user.js` 全文 → 保存
2. 登录画廊一次后即可正常使用。

## 在别的电脑上浏览

同步目标是**画廊服务器**，与在哪台电脑浏览无关——任何设备上刷到的图都会汇入服务器的
`~/Pictures/instagram-scraped/`。画廊已反代到公网 `https://gallery.example.com:8443`，
推荐统一使用这个地址（固定、HTTPS、不在家也能同步）。在新电脑上：

1. 装 ScriptCat/Tampermonkey 并导入本脚本，首次运行会弹窗询问画廊地址，
   填 `https://gallery.example.com:8443`（或局域网 `http://192.168.1.100:3000`），
   之后可随时通过脚本菜单「设置画廊地址」修改；左下角待机徽章会显示当前发往的地址；
2. 在那台电脑的浏览器里打开画廊地址**登录一次**（脚本回传需要会话 cookie）；
3. 第一次同步时脚本管理器会询问是否允许连接该地址，选允许。

## 注意

- 画廊地址默认 `http://localhost:3000`，可通过 Tampermonkey 菜单「设置画廊地址」修改；
  换域名后 Tampermonkey 会弹窗询问是否允许连接，选允许
- 徽章提示「请先登录画廊」→ 去画廊登录后刷新 Instagram 页面
- 徽章提示「画廊未连接」→ 确认画廊服务已启动
- 收录的图集在 `~/Pictures/instagram-scraped/{用户名}/`；若画廊当前扫描的是其他目录，
  需在画廊设置里把扫描目录切回 `~/Pictures/instagram-scraped` 才能看到
- 仅限个人自用。批量自动化采集违反 IG 服务条款，本方案的请求量与真人浏览一致，
  但请勿在脚本基础上再加自动滚动等自动化行为
